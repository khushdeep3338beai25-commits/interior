 
# AUREVÉ — Interior Design Studio

AUREVÉ is a premium interior design studio website inspired by timeless architecture, contemporary aesthetics, and sophisticated living. It showcases beautifully curated interiors through immersive visuals, elegant typography, and refined interactive experiences.

## ✨ Features

- **Luxury Visual Experience** — Minimal, elegant, and sophisticated interface.
- **Immersive Hero Section** — Full-screen architectural imagery with cinematic overlays.
- **Premium Typography** — Refined typography paired with a modern editorial layout.
- **Smooth GSAP Animations** — Fluid transitions and scroll-triggered effects.
- **Interactive Project Previews** — Engaging project cards with hover interactions.
- **Animated Statistics** — Dynamic counters highlighting studio achievements.
- **Image Reveal Effects** — Elegant clipping, reveal, and transition animations.
- **Parallax Scrolling** — Subtle depth and movement for an immersive experience.
- **Responsive Navigation** — Modern navigation with seamless interactions.
- **Fully Responsive** — Optimized for desktop, tablet, and mobile devices.

## 🎨 Design Philosophy

AUREVÉ brings together architectural precision and artistic expression.

Inspired by contemporary luxury, the website uses a refined visual language of immersive photography, sophisticated layouts, subtle motion, and generous whitespace to communicate elegance and creativity.

Every interaction is designed to feel intentional, creating a digital experience that reflects the studio's approach to thoughtful interior design.

## 🛠️ Built With

- HTML5

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/thecoretechnology/thecore-100-days-web.git
   ```

2. Navigate to the project directory:

   ```bash
   cd thecore-100-days-web/phase-3-complete-websites/site/day-058-interior-design
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code.
