# AUREVÉ — Interior Design Studio

AUREVÉ is a luxury interior design studio website that showcases timeless elegance, contemporary architecture, and sophisticated living spaces. Designed with an emphasis on immersive visuals, refined typography, and cinematic animations, AUREVÉ delivers a premium digital experience inspired by modern luxury interiors.

The website combines minimalist aesthetics with interactive storytelling, smooth transitions, and elegant motion effects to create a visually engaging experience.

## ✨ Features

- Premium luxury interior design aesthetic
- Minimalist and sophisticated user interface
- Immersive full-screen hero section
- Transparent navigation with elegant interactions
- Cinematic image overlays and transitions
- GSAP-powered animations and interactions
- GSAP ScrollTrigger-based scroll animations
- Animated hero text reveals
- Smooth image reveal effects
- Interactive project preview cards
- Animated statistics and counters
- Parallax scrolling effects
- Sophisticated hover interactions
- Smooth section transitions
- Responsive navigation and layouts
- Optimized experience across desktop, tablet, and mobile

## 🎨 Design Philosophy

AUREVÉ represents the intersection of contemporary creativity and timeless sophistication.

The visual identity focuses on:

- Elegant and refined typography
- Architectural and interior photography
- Minimalist layouts with generous whitespace
- Sophisticated color palettes
- Cinematic imagery and subtle overlays
- Smooth, purposeful animations
- An immersive and editorial-style browsing experience

Every section is designed to communicate the studio's creative vision while highlighting the beauty of thoughtfully designed spaces.

## 🚀 Getting Started

Follow these steps to run AUREVÉ locally.

### 1. Clone the Repository

```bash
git clone https://github.com/thecoretechnology/thecore-100-days-web.git
```

### 2. Navigate to the Project Folder

```bash
cd thecore-100-days-web
```

Navigate to the AUREVÉ project directory:

```bash
cd phase-3-complete-websites/site/day-058-interior-design
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Run the Website

Open `index.html` directly in your browser.

Alternatively, install the **Live Server** extension in Visual Studio Code and click **Go Live** for a better development experience.

## ✨ Animation & Interaction Experience

AUREVÉ uses motion and visual storytelling to create an immersive browsing experience.

- **Hero Animations:** Cinematic text reveals and smooth entrance transitions.
- **Image Reveals:** Sophisticated image transitions and reveal effects.
- **Scroll Animations:** GSAP ScrollTrigger-powered content animations.
- **Project Interactions:** Interactive project cards and hover effects.
- **Animated Statistics:** Dynamic counters and engaging visual elements.
- **Parallax Effects:** Subtle depth and movement while scrolling.
- **Smooth Transitions:** Fluid transitions between sections and elements.

## 📱 Responsive Design

AUREVÉ is designed to deliver a consistent experience across different screen sizes.

- **Desktop:** Immersive layouts, architectural imagery, and cinematic animations.
- **Tablet:** Adaptive layouts and optimized navigation.
- **Mobile:** Touch-friendly interactions, responsive sections, and optimized visuals.
