
# AUREVÉ — Interior Design Studio

AUREVÉ is a luxury interior design studio website that celebrates timeless elegance, modern architecture, and sophisticated living spaces. Featuring immersive visuals, refined typography, and elegant animations, the website delivers a premium digital experience inspired by contemporary interior design.

## ✨ Features

- Luxury and minimalist website design
- Elegant typography and premium aesthetics
- Immersive full-screen hero section
- Cinematic image overlays and transitions
- Smooth scroll-based animations
- GSAP-powered interactive animations
- Interactive project preview cards
- Animated statistics section
- Sophisticated image reveal effects
- Smooth hover interactions
- Parallax scrolling effects
- Modern and responsive navigation
- Fully responsive layouts for desktop, tablet, and mobile

## 🎨 Design Philosophy

AUREVÉ combines contemporary creativity with timeless sophistication.

The visual identity embraces elegant typography, architectural photography, refined layouts, generous whitespace, and subtle motion to create an atmosphere of understated luxury.

Every section and interaction is thoughtfully designed to showcase beautiful living spaces while delivering an immersive and engaging browsing experience.

## 🛠️ Built With

- **HTML5** — Website structure and semantic markup
- **CSS3** — Styling, layouts, transitions, and responsive design
- **JavaScript (ES6+)** — Interactive functionality and dynamic experiences
- **GSAP** — Advanced animations and transitions
- **GSAP ScrollTrigger** — Scroll-based animation effects

## 🚀 Getting Started

Follow these simple steps to run the website locally.

1. Clone or download the project.
2. Extract the project files if downloaded as a ZIP.
3. Open the project folder in Visual Studio Code.
4. Launch `index.html` in your browser.

Alternatively, install the **Live Server** extension in Visual Studio Code and select **Open with Live Server** for a better development experience.
