
# AUREVÉ — Interior Design Studio

**AUREVÉ** is a luxury interior design studio website that celebrates timeless elegance, modern architecture, and sophisticated living spaces. Designed with immersive visuals, refined typography, and smooth animations, it delivers a premium digital experience.

## ✨ Features

- Luxury and minimalist website design
- Elegant typography and premium aesthetics
- Immersive full-screen hero section
- Smooth scroll-based animations and transitions
- Interactive project preview cards
- Animated statistics section
- Modern navigation and responsive layouts
- Sophisticated image reveal and hover effects
- Fully responsive design

## 🎨 Design Philosophy

AUREVÉ combines contemporary creativity with timeless sophistication, showcasing thoughtfully curated interiors through an elegant and immersive digital experience.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- GSAP Animations
- Responsive Web Design

## 🚀 Getting Started

1. Clone the repository.
2. Open the project folder.
3. Launch `index.html` in your browser.

Alternatively, use VS Code Live Server for local development.
